# Maths2Models

> Where Math Meets Intelligence

Educational platform for IITM BS Data Science — notes, videos, PYQs, and resources.

## Structure

| Folder | URL | Purpose |
|---|---|---|
| `foundation/` | `/foundation/` | Foundation level courses |
| `diploma/` | `/diploma/` | Diploma level courses |
| `degree/` | `/degree/` | Degree level courses |
| `blog/` | `/blog/` | Articles and posts |
| `projects/` | `/projects/` | Project showcase |
| `resources/` | `/resources/` | Notes, PYQs, sheets |
| `data/` | — | All JSON content files |

## Update Content

Edit files in `data/` only. No HTML editing required.

## Deploy

Hosted on GitHub Pages — push to `main` branch to deploy.
